# ตุ๊กตุ๊กเศรษฐีไทย (เดิมชื่อ รถไฟเศรษฐีไทย)

เกมกระดานรถไฟสายเหนือ แข่งกันเป็นเศรษฐีรถไฟ เดินทางไปจุดหมาย ซื้อกิจการท้องถิ่น ตอบควิซ และหนีผีปอบ
เล่นบนเบราว์เซอร์ได้ทั้งมือถือ iPad และคอม 2–4 คน

## วิธีเล่น
- **เล่นเครื่องเดียว** ผลัดกันส่งเครื่อง หรือเล่นกับบอท
- **เล่นออนไลน์กับเพื่อน** คนหนึ่งกด "สร้างห้องใหม่" แล้วส่งรหัส 4 ตัวให้เพื่อน เพื่อนเปิดลิงก์เดียวกันแล้วใส่รหัส ไม่ต้องสมัครอะไร
  - เจ้าของห้องต้องเปิดเกมค้างไว้ตลอดเกม (สถานะเกมอยู่ที่เครื่องเจ้าของห้อง)
  - เชื่อมต่อแบบเครื่องต่อเครื่องผ่าน PeerJS ถ้าเน็ตมือถือบางค่ายต่อไม่ติด ให้ลองใช้ Wi-Fi

## ใส่ภาพการ์ด
1. `python prepare_cards.py "<โฟลเดอร์ภาพจาก ComfyUI>"` จะได้โฟลเดอร์ `cards/`
2. ในหน้า repo บน GitHub เข้าโฟลเดอร์ `cards` → **Add file › Upload files** → ลากไฟล์ทั้งหมดไปวาง → **Commit changes**
3. รอ 1–2 นาที แล้วรีเฟรชเกม

## ไฟล์
- `index.html` ตัวเกม
- `p2p.js` ระบบเล่นออนไลน์แบบเครื่องต่อเครื่อง
- `prepare_cards.py` แปลงภาพการ์ด
